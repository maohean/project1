# HEAN Technology Portfolio

A responsive bilingual (English / Khmer) personal technology profile.

## Run locally
Open `index.html` in a modern browser. Fonts (Kantumruy Pro for Khmer, Open Sans for English) are self-hosted in `assets/fonts/` and icons are an inline SVG sprite, so the page renders correctly offline.

## Included visual assets
- `assets/helpdesk-illustration.webp` — Help Desk focus card
- `assets/network-server-infrastructure.webp` — Network configuration practice panel
- `assets/python-logo.webp` — Python Programming focus card

The website is front-end only. The contact form is a demo until connected to an email or form service.

## Orbis portfolio assistant
The page includes a floating Orbis assistant in the bottom-right corner. It has animated artwork, English / Khmer interface text, suggested questions, and local responses that link to relevant portfolio sections. It runs entirely in the browser and does not connect to a live AI service or store conversations.

The assistant uses `assets/robot-bot.webp` (3D robot) for both its launcher and the chat panel character in the chat panel.

## Language selector
The header includes clickable United Kingdom and Cambodia flag buttons. Select either flag to switch between English and Khmer; the selected language is remembered in the browser.

## Technology-icon hero visual
The introduction area places four floating technology badges around the profile portrait: Network, Security, Data, and Code. Each badge uses a simple inline SVG icon, switches between English and Khmer with the language selector, and has a gentle floating animation. The decorative motion respects the device's reduced-motion accessibility setting.


## Exploring section refresh
The three introductory cards now keep their IT support, networking, and code illustrations while removing the small 01 / 02 / 03 labels. The section has a soft blue-violet-warm gradient, animated ambient color, gentle card lift, and a light sweep on hover. Motion is reduced automatically when the device requests reduced motion.
